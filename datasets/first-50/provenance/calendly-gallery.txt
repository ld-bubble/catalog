Calendly

Calendly is a scheduling web application that syncs with personal and professional calendars to display real-time availability and remove back-and-forth communication. The software allows users to configure custom event types, set specific work hours, and insert buffer times between appointments, generating unique URLs or embeddable booking pages where recipients directly select an open time slot.
